# Local client data

The Windows helper uses the unmodified CASC reader from [CascLib](https://github.com/ladislav-zezula/CascLib), pinned in the Git submodule. See the accompanying CascLib license.

DB2 and hotfix decoding use the [WoWSims Forever v1.0.3 db2tool packages](https://github.com/wowsims/forever/tree/v1.0.3/tools/db2tool). See [upstream notices and license texts](https://github.com/wowsims/forever/blob/v1.0.3/tools/db2tool/NOTICES.md) and the accompanying WoWSims notice.

The DB2 schemas and FileDataID mapping come from the [WoWDBDefs](https://github.com/wowdev/WoWDBDefs) submodule and are used under CC BY-SA 4.0. See the accompanying WoWDBDefs license.

Image decoding uses [wow-blp 0.7.0](https://github.com/wowemulation-dev/warcraft-rs/tree/v0.7.0/file-formats/graphics/wow-blp), licensed under MIT or Apache-2.0.
