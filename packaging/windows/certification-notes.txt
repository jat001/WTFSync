WTFSync is a local desktop utility for synchronizing World of Warcraft addon data between accounts on the same computer. The current version supports BiaoGe. The application does not require a Battle.net login or any account password.

Offline review:
Copy the PowerShell snippet below into a Windows PowerShell session to create a minimal synthetic game directory. It contains two made-up accounts and characters, with no real SavedVariables. It refuses to overwrite an existing directory. The sample is a directory fixture, not a game installation.
1. Launch WTFSync. Select the WorldOfWarcraft folder printed by the script from the workbench directory picker, or Settings (设置) > Game (游戏).
2. On Workbench (工作台), select accounts 100000001#1 and 100000002#2, then click Sync now (立即同步).
3. Verify four generated files in _classic_titan_/Interface/AddOns/BiaoGeAccounts: two account Lua files, a loader and a TOC. The Interface value is read from the synthetic client's version.
4. Repeating sync without source changes preserves file content and modification times.
5. With automatic sync enabled and the application open, edit a character level in either synthetic SavedVariables/BiaoGe.lua file and save. That account output should update after the debounce interval.
6. Close and reopen the app. The selected directory, accounts and automatic sync setting should persist. Startup synchronization should report that the files are current.
7. The privacy policy is available in About (关于) > Privacy policy (隐私政策).

Live game use requires a local World of Warcraft installation and BiaoGe. Source SavedVariables files are read-only to WTFSync. Generated output becomes visible in BiaoGe after a game reload. Do not copy the synthetic review fixture into a real game installation.

runFullTrust rationale:
WTFSync is a Tauri desktop application that runs as a normal user. It needs to read and watch addon SavedVariables under a user-selected game directory and create or replace its generated BiaoGeAccounts files under Interface/AddOns, outside the MSIX installation folder. It also stores local configuration in application data and can open the selected directory in the system file manager. No administrator privileges, elevation, services, kernel components or remote account synchronization are used.

Runtime:
The x64 package targets Windows 10 build 19041 and newer, including Windows 11. It uses Microsoft Edge WebView2 Evergreen. If WebView2 is missing, a native dialog offers Microsoft's official download page and the app exits without synchronizing.

Local validation boundary:
Release build and 38 automated tests passed. The development package with Store identity passed directory selection, byte-compatible generated output, repeat sync, filesystem monitoring, configuration persistence and privacy-page checks on the current Windows host. Full self-signed MSIX installation and upgrade, Windows 10 runtime testing, missing-WebView2 runtime testing and WACK have not been completed.


PowerShell snippet for offline review:
param([string]$Destination = (Join-Path $env:TEMP 'WTFSyncStoreReview/WorldOfWarcraft'))
$ErrorActionPreference = 'Stop'
$Destination = [IO.Path]::GetFullPath($Destination)
if (Test-Path -LiteralPath $Destination) { throw 'Choose a new sample directory.' }
function Put([string]$RelativePath, [string]$Text) {
    $file = Join-Path $Destination $RelativePath
    [IO.Directory]::CreateDirectory([IO.Path]::GetDirectoryName($file)) | Out-Null
    [IO.File]::WriteAllText($file, $Text, [Text.UTF8Encoding]::new($false))
}
Put '.build.info' "Active!DEC:1|Version!STRING:0|Product!STRING:0`n1|3.80.2.12345|wow_classic_titan`n"
Put '_classic_titan_/.flavor.info' "Product Flavor!STRING:0`nwow_classic_titan`n"
Put '_classic_titan_/Interface/AddOns/BiaoGe/BiaoGe.toc' "## Title: Synthetic review fixture`n"
foreach ($id in '100000001#1','100000002#2') {
    $character = if ($id -eq '100000001#1') { 'SampleOne' } else { 'SampleTwo' }
    Put "_classic_titan_/WTF/Account/$id/SavedVariables/BiaoGe.lua" @"
BiaoGe = {
    ["realmName"] = { [4533] = "SampleRealm" },
    ["playerInfo"] = { [4533] = { ["$character"] = {
        ["class"] = "WARRIOR", ["level"] = 80,
        ["faction"] = "Alliance", ["iLevel"] = 200,
    } } },
}
"@
}
Write-Output "Select this synthetic directory in WTFSync: $Destination"
